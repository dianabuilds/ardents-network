# Protected Endpoint launch

The Endpoint command stages an authenticated generation for platform-prepared
accounts and roots. Replacement requires completion of the original Endpoint
invocation, stopped activation sockets, and kernel quiescence. The platform
installs units and starts the participant. The running Endpoint independently
retains and verifies the original generation, process and manager.

The [Endpoint runtime contract](../../../../docs/technical/endpoint-service-runtime.md)
describes release verification, staging, and runtime admission.
