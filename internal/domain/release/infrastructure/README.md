# Infrastructure Release artifacts

The package prepares canonical program and unit descriptor bytes and checks the
exact authorized pair for a fixed Source or Node invocation. Enrollment owns
the original inventory and independent initial pin. Release owns signatures and
retained floors. Control consumes this package for offline preparation and
predecessor verification. The platform command consumes the original artifact
proofs when it admits a configured infrastructure role.

The `ardents-next infrastructure authenticate-initial` and
`authenticate-candidate` commands use the Source distribution inspection in this
package. It keeps the distribution and inspection history separate, verifies the
original artifacts through Enrollment and Release, and closes the verifier before
returning outcomes and digests for the CLI receipt.

The [operator procedure](../../../../docs/operations/node-role-platform-lifecycle.md)
describes platform deployment. The canonical systemd unit template belongs to
the [systemd adapter](../../../platform/systemd/infrastructure_unit_linux.go).
