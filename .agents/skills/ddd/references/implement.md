# Implement one admitted boundary

Use only for an explicitly selected implementation task. For a plan-only request,
report proposed behavior and evidence without editing code.

Start from the current owner, real consumers and domain-map interaction checklist.
Semantic rules stay with their owner; composition orders genuine owners and
physical lifetimes. Preserve original errors and effect order.

Use the single Go module and [Go guidance](stacks/go.md). A new package needs
cohesive behavior, doc.go, exact registration, behavior tests and a real non-test
caller in the same change. Avoid universal aggregates and speculative ports.

Events require an actual notification need. An outbox, broker or asynchronous
cross-domain call is not a default. Revocation, spend and cleanup preserve their
accepted synchronous ordering.

Move one complete responsibility with its oracles. Verify both neighbors and
retained bytes. Preserve old/new Route isolation; wrappers, callbacks and process
bridges are not migration solutions. Run quick-check while coding, full check
before integration and applicable native/installed profiles. Missing prerequisites
are invalid environments. Update current owners; distinguish component readiness,
issue acceptance, integration and qualification.
