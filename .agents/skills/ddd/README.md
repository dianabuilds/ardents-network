# DDD skill for Ardents

[SKILL.md](SKILL.md) is the entry point for bounded audits, design and selected
Go implementation using the repository's existing owners. Load only the needed
reference: [assessment](references/assess.md),
[implementation](references/implement.md), or [Go ownership](references/stacks/go.md).
Domain contracts stay in the current technical owners and domain map; the skill
adds no parallel glossary, package model, deployment rule or task authorization.

The [skills lock](../../../skills-lock.json) retains upstream import metadata;
its hash has not been verified as a checksum of this maintained local adaptation.
Local edits are reviewed in this repository rather than inferred from that entry.
