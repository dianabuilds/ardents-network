# Documentation archive

This is historical evidence, not a competing current specification or work queue.
Start with [current documentation](../README.md). Records are retained unchanged;
the [manifest](manifest.json) records original path, SHA-256, source revision,
disposition and current owner for every transfer or snapshot.

Hashes cover the captured file bytes, including encoding and line endings;
the source revision identifies their original Git layout and context. A captured
checkout can have CRLF where the older Git blob used LF. Archive attributes
preserve captured bytes without conversion. The previously untracked draft has
no claimed Git source revision.

Archived accepted decisions retain explicitly surviving clauses. A later ADR
replaces only its stated scope: notably ADR-0117 changes Service byte identities
and old-state handling, preserving security/lifecycle and Terminal receipt rules.
An unaccepted/open proposal stays unaccepted/open. Archival closes no unresolved
finding and establishes no new candidate or qualification. Current owners and
GitHub hold today's contract and acceptance boundary.

## Reading historical links

Original texts keep their original relative links and source inventories. Use
the pinned source link below to follow those links in their original repository
layout; their former paths do not promise a current implementation. Use the
current-owner link for maintained work. External receipts retain their declared
locations and hashes, including original failures and fixture limits.
