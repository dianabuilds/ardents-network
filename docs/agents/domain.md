# Domain docs

This repository uses a single domain context.

## Sources

Before exploring or changing a domain:

1. read the root `CONTEXT.md`;
2. read the ADRs under `docs/adr/` that affect the work;
3. read the nearest product, protocol, engineering, security, or operations
   contract referenced by those sources.

Use the glossary vocabulary from `CONTEXT.md` in issue titles, acceptance
criteria, tests, interfaces, and implementation notes. Do not replace defined
terms with avoided synonyms.

If proposed work conflicts with an accepted ADR, state the conflict explicitly
instead of silently overriding the decision.
