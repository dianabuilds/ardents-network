# Triage labels

The engineering skills use five canonical triage roles. Their tracker strings
for this repository are:

| Canonical role | Tracker status | Meaning |
|---|---|---|
| `needs-triage` | `needs-triage` | A maintainer must evaluate the issue |
| `needs-info` | `needs-info` | The issue is waiting for more information |
| `ready-for-agent` | `ready-for-agent` | Fully specified and independently implementable |
| `ready-for-human` | `ready-for-human` | Requires human judgment or implementation |
| `wontfix` | `wontfix` | Will not be actioned |

Use the exact tracker status from this table on the issue's `Status:` line.
