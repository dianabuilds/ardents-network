# Public anonymous carrier with private services

Ardents will be an internal application network with a public, independently
operated carrier and private or capability-gated Services and Spaces. A
membership-gated carrier was rejected because a small known participant set
weakens the anonymity set and turns network admission into a global identity and
governance problem. A clearnet exit is outside the first product because it adds
a different abuse, legal, routing, and endpoint-security contract.

This decision fixes the product boundary, not a routing protocol or incentive
system.
