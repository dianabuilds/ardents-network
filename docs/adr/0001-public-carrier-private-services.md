# Public carrier with application-controlled services

Ardents will be an internal application network with a public, independently
operated carrier. A Service may be open to anyone knowing its exact destination
or enforce its own Application authorization; the carrier does not create a
membership or `Space` model. A membership-gated carrier was rejected because a
small known participant set weakens the anonymity set and turns network admission
into a global identity and governance problem. A clearnet exit is outside the
first product because it adds a different abuse, legal, routing, and
endpoint-security contract.

This decision fixes the product boundary, not a routing protocol or incentive
system.
