# Restart main as a greenfield research workspace

The previous Go/Waku implementation and its documentation are preserved in the
remote `old` branch. `main` starts again from the product contract, threat model,
domain language, and decision-oriented research queue because the legacy module
and authority boundaries encoded assumptions that no longer match the intended
product. Compatibility with legacy APIs, data, or architecture is not a default
constraint; individual ideas may return only through current evidence and an
explicit decision.

No production language or networking foundation is selected by this reset.
