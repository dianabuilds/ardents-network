# Stage route research before public-network implementation

Ardents separates its durable Product Core from delivery horizons. Only the
Ubuntu controlled Carrier Lab is current implementation scope; the Named
Unlisted Site is conditional on its result, while permissionless naming,
Bridges, production packaging and updates, multiparty control, public
contribution, cross-platform qualification, and stable-network operations remain
later promotion gates. This prevents an unvalidated route hypothesis from
turning the complete public-network threat model into one immediate backlog,
without weakening any security claim: a deferred condition withholds its claim
rather than being silently omitted.
