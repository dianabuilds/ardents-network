## Fixed implementation requirements

1. Export only the seven declarations frozen by the transaction-format
   proposal. `Apply` and terminal `Recover` are the only operations. `Request`
   carries injected `WorkControl` and `SelfTest`; production never constructs,
   replaces, type-asserts, or bypasses them.
2. Use the exact initialized root and two-file generation format. S7.2-01 does
   not bootstrap an empty root, parse TUF, migrate schema, or accept any plan
   other than exact `no-op-v1`.
3. Store all nine immutable state entries with the frozen explicit binary
   codec. Each predecessor is SHA-256 of exact prior entry bytes; the first
   commits the inspected predecessor terminal entry. Never overwrite an entry.
4. Stage and verify payload plus manifest once. Activation moves that complete
   directory and atomically replaces only `current`; never delete the selected
   generation or recreate the moved manifest.
5. Detect an identical committed request before allocation, staging, Adapter
   calls, or journal writes. Return the original generation and exact terminal
   facts. Conflicts never reuse that generation.
6. Require the previous payload with its stored authorization. Observe every
   cleanup, close, sync, and atomic-publication error; cleanup is bounded by the
   fixed five-second ceiling and no error is discarded with `_ =`.
7. D0 is independent test evidence: exact floor bytes and custody commitments
   remain unchanged, with zero secret reads and zero Authority mutations.
