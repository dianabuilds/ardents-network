calling an Update Transaction production encoder, hash helper, or schema

arrays, and locally constructed unsigned big-endian integers.

- entries in ordinal order: UTF-8 `alpha\n`, UTF-8 `beta\n`;
- source schema version/generation: `1` / `0`;
- candidate schema version/generation: `2` / `1`;
- transaction generation: source `0`, candidate `1`;

- source record predecessor: 32 zero bytes;
- candidate record predecessor: SHA-256 of the exact source record.

`m3-s7.2-06-brief.md`. Each schema-current record was independently assembled
as `ARDUPD01`, kind `5`, version `1`, zero flags, big-endian body length `160`,
then the D3 body. Both complete records are `176` bytes.
